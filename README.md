## Things I believe

- **Your data deserves an export button.** Software that holds your data hostage isn't a tool, it's a lease.
- **Self-hosting isn't about saving money** — it's about not asking permission.
- **A README is a promise.** Ship the thing before you write the promise.

## Things I've built

- **[Django Query Optimization](https://github.com/tony-nyagah/django-query-optimization-practice)** — a hands-on demo of the N+1 query problem and how to fix it, with tests that compare query counts.
- **[Nametag Filler](https://github.com/tony-nyagah/nametag-filler)** — generate print-ready conference badges from a spreadsheet and a template.
- **[Email Verifier](https://github.com/tony-nyagah/email-verifier)** — a Go app that checks email syntax, DNS, and SMTP responses without sending mail.
- **[Simple RAG](https://github.com/tony-nyagah/simple_rag)** — ask questions over your documents using local CPU embeddings, with Groq for answer generation.
